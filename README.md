# IPsecLens AI
### Evidence-aware IPsec analysis · SIH 26160 · NTRO · Software / Blockchain & Cybersecurity

A local FastAPI + React prototype that parses capture metadata, tracks directional ESP/AH observations,
evaluates explicit policy checks, classifies synthetic traffic profiles, and produces standalone reports.

**UNKNOWN ≠ SECURE. No finding ≠ safe. AI confidence ≠ attack probability.**
No payload decryption, scanning, cloud service or LLM API. All experiments use supplied files or isolated labs.

## Quick start

Python 3.13 and Node 24 are the validated runtimes.

    make install
    make demo
    make backend

In a second terminal:

    make frontend

Open http://127.0.0.1:5173. Backend: http://127.0.0.1:18760.
OpenAPI JSON: http://127.0.0.1:18760/openapi.json. CDN-dependent documentation pages are disabled.
Dependencies install from registries once. Training, fixtures, analysis, dashboard and reports work offline afterward.
The fixed model is generated by make train / make demo. No uploaded model is accepted.

1. Choose **New Analysis** and upload demo/strong/strong.pcap.
2. Add demo/strong/telemetry.json, select MODERN, and run.
3. Inspect Protocol Analysis, Security Associations, Encrypted Traffic AI, Findings and Threat Matrix.
4. Download the technical HTML report from Reports.
5. Repeat with weak, replay and partial fixtures.

All bundled PCAPs and telemetry are explicitly **SYNTHETIC FIXTURE** data, not captured VPN deployments.
A high strong-demo score requires the matching synthetic telemetry. Uploading only its PCAP correctly leaves ESP configuration unknown.

## Implemented

- Bounded streaming PCAP / PCAPNG enhanced-packet reader; Ethernet, VLAN, raw IP, Linux cooked v1/v2.
- IPv4 and IPv6 common extension traversal; fragments and unsupported chains explicitly reported.
- IKEv1 identification; IKEv2 headers, exchanges, visible SA proposals, transforms, attributes and KE group.
- Native ESP, NAT-T marker separation, NAT keepalives, basic AH SPI/sequence/next-header visibility.
- Directional SA statistics and duplicate/regressing/gapped sequence signals.
- Capture-bound normalized strongSwan/XFRM JSON telemetry; every imported property is ASSISTED.
- MODERN, COMPATIBILITY, STRICT policies; domain scores, unknown coverage and deterministic findings.
- Random forest selected against logistic regression and gradient boosting on synthetic validation groups.
- Seven synthetic traffic classes, 22 metadata features, probabilities, abstention and model integrity check.
- SQLite analysis history, safe HTML reports, threat matrix and recommendation-only strongSwan snippets.
- React analyst workspace with eleven views, responsive layout and source badges.
- Isolated Docker strongSwan config generator and local capture CLI.

## Tests and operations

    make test
    .venv/bin/python -m compileall -q backend training scripts
    .venv/bin/python -m scripts.benchmark
    .venv/bin/python -m scripts.analyze demo/partial/partial.pcap
    make clean-demo

Browser release checks optionally use system Selenium + Chromium + chromedriver:

    python3 scripts/browser_walkthrough.py

The web app binds loopback and must run without root. It has no multi-user authentication and must not
be exposed publicly. No permissive CORS. Captures are removed after analysis unless retention is selected.
Runtime state is ignored by Git under runtime/. See .env.example for configurable parser bounds.
Environment variables must be exported by the operator; .env is an example, not automatically loaded.

## Important limits

IKE_SA_INIT proposals describe the IKE SA, never automatically the ESP Child SA. Encrypted exchanges
remain opaque. Mode, configured PFS, lifetime, replay window and ESN require endpoint evidence.
Passive sequence anomalies do not establish replay acceptance. Observed duration is not configured lifetime.
No implementation/version/CVE attribution is made.

ML metrics measure separable synthetic profile recognition, not real application accuracy.
The model may be confidently wrong on real traffic. VPN SAs can multiplex applications.
The first 2048 packets per directional SA feed inference; all bounded packets feed sequence analysis.

Docker integration is unverified on this host because daemon access is denied.
Real namespace tunnels and captured workloads are now verified; synthetic fixtures remain separately labelled.
Raw swanctl/XFRM parsers and offline PDF export are implemented and tested. Endpoint attestation and fragment reassembly remain unsupported.
